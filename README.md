### Rangkuman Materi
**1. Prompt Engineering**
- Prompt adalah instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu. 
- Struktur prompt yang baik terdiri dari 4 elemen: *Role* (Peran), *Task* (Tugas), *Context* (Konteks), dan *Format*.
- Keuntungan Prompt Engineering: Meningkatkan performa model AI, mengurangi bias dan respons yang ofensif, meningkatkan kontrol (*predictability*), serta memberikan pengalaman yang lebih baik.

**2. Git vs GitHub**
- **Git:** Adalah sistem *version control* terdistribusi (DVCS) yang diciptakan oleh Linus Torvalds pada tahun 2005. Git berfungsi untuk melacak siapa, kapan, dan apa saja perubahan yang dikelola pada kode secara lokal di komputer.
- **GitHub:** Adalah platform berbasis web yang digunakan untuk menyimpan *repository* Git secara online dan mendukung kolaborasi tim.
- **Git Workflow:** Alur kerja penyimpanan kode terbagi menjadi tiga tahapan, yaitu *Working Directory*, *Staging Area* (menggunakan `git add`), dan *.git directory/Repository* (menggunakan `git commit`).

**3. Perintah Dasar Git (Essential Commands)**
- `git init`: Untuk memulai *repository* baru.
- `git add .` atau `git add -A`: Untuk memindahkan semua file modifikasi ke *staging area*.
- `git commit -m 'message'`: Untuk menyimpan perubahan file secara permanen ke *Repository* lokal.
- `git push origin main`: Untuk mengirim *branch* saat ini ke *remote repository* di GitHub.

### Poin-poin Penting yang Dipelajari
- Mengetahui cara membuat instruksi untuk AI yang spesifik dengan menyertakan *Context* dan *Format*.
- Memahami perbedaan cara kerja antara menyimpan status proyek di komputer (*Commit*) dan menyinkronkan data ke internet (*Push*).
- Belajar cara menghubungkan *repository* lokal dengan *repository* di GitHub melalui perintah terminal seperti `git remote add` dan `git clone`.
